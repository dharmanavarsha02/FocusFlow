# FocusFlow — Student Focus Hub

FocusFlow is a student productivity website built using HTML, CSS, and JavaScript. It helps students organize tasks and manage focused study sessions.

## Features

- Add and manage tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by status
- Track task completion progress
- Focus timer for study sessions
- Save tasks using browser localStorage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage

## Live Demo

[Open FocusFlow](https://dharmanavarsha02.github.io/FocusFlow/)

## How to Run Locally

1. Clone this repository:

   `git clone https://github.com/dharmanavarsha02/FocusFlow.git`

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Purpose

This project was created to practice frontend web development, JavaScript DOM manipulation, and browser storage.
